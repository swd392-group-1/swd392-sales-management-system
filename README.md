# Sales Management System

This repository contains the SWD392 team project for Group 1, a team of five members.

- **Repository:** `swd392-group-1/swd392-sales-management-system`
- **Project topic:** Sales Management System
- **Current COMET phase:** Requirements Modeling

## Project status

Detailed requirements are still being elicited. This initial setup provides a shared structure for collaboration and documentation. Functional requirements, actors, and use cases have not yet been defined. Architecture, database schema, APIs, controllers, services, and design patterns have not been selected.

## Repository structure

| Path | Purpose |
| --- | --- |
| `docs/01-requirements/` | Requirements elicitation and requirements modeling artifacts. |
| `docs/02-analysis/` | Analysis artifacts developed in a later phase. |
| `docs/03-design/` | Design artifacts developed in a later phase. |
| `docs/ai-usage/` | Records of AI assistance and human verification. |
| `src/` | Source code when implementation begins. |
| `tests/` | Tests when verifiable requirements and implementation are available. |
| `.github/ISSUE_TEMPLATE/task.md` | Template for team tasks. |
| `.github/pull_request_template.md` | Template for reviewing proposed changes. |

Empty directories contain `.gitkeep` placeholders so Git can track the structure.

## Team workflow

1. Create a task issue with an objective, COMET phase, deliverables, and acceptance criteria.
2. Assign the task to a team member and record any dependencies.
3. Work on a separate branch and keep changes focused on the task.
4. Open a pull request against `main` using the provided template.
5. Ask another team member to review the changes before merging.

Link issues, requirements, use cases, documents, and tests when those artifacts exist. If a requirement or use case is not yet defined, state that explicitly instead of inventing an identifier.

## AI usage

Disclose AI assistance in issues and pull requests. Record the tool, purpose, affected artifacts, and human verification in `docs/ai-usage/` when AI is used. Team members remain responsible for validating and understanding submitted work.

## Verification

This repository currently contains documentation and collaboration templates only. No application, build process, or automated test suite has been configured.
